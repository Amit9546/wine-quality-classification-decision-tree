# Wine Quality Classification and Analysis

A machine learning project built with Python and Scikit-Learn that performs wine type classification and regression analysis using the **Wine Quality dataset** (`winequalityN.csv`). The repository covers data preprocessing, missing value handling, and evaluation across multiple models[cite: 2].

## 📋 Features

* **Data Preprocessing & Encoding**: Handles missing values with mean imputation and encodes categorical wine types using `LabelEncoder`[cite: 2].
* **Decision Tree Classifier**: Implements `DecisionTreeClassifier` (using entropy criteria and max depth) to predict wine categories with performance metrics[cite: 2].
* **Linear Regularization Models**: Trains and evaluates **Ridge** and **Lasso** regression models to analyze feature relationships and performance[cite: 2].
* **Model Evaluation**: Assesses classification and regression performance using accuracy scores, confusion matrices, and model scoring[cite: 2].

## 🛠️ Tech Stack

* **Python**[cite: 2]
* **Pandas & NumPy** (Data manipulation and cleaning)[cite: 2]
* **Scikit-Learn** (Decision Trees, Ridge, Lasso, metrics, and preprocessing)[cite: 2]
